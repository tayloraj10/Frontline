# New Machine Setup — Files Not in Git

Reference for setting up the repo on a new machine (e.g. personal Mac). These files are gitignored on purpose (secrets/local config) so `git clone` won't bring them over — you'll need to recreate or copy them manually.

**Before you switch machines**: commit and push the current branch (`phase2/capacitor-scoping`). `frontend/scripts/` (the `dev.mjs` LAN-IP dev-server helper) and `dev-docs/capacitor-scoping-2026-08-04.md` are currently **untracked**, not gitignored — if you clone before pushing, you won't get them either way, doc or no doc.

## 1. `backend/.env`

Currently set locally (copy these values over securely — don't retype from memory/screenshots):
```
DATABASE_URL=
SUPABASE_URL=
SUPABASE_SERVICE_ROLE_KEY=
ENVIRONMENT=
ADMIN_API_SECRET=
```
`backend/.env.example` has the full list of *possible* vars (R2 credentials, `CORS_ORIGINS`, `SENTRY_DSN`) — the ones above are what's actually populated in the current local file; R2 and Sentry aren't currently set locally.

## 2. `frontend/.env.local`

Currently set locally:
```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
NEXT_PUBLIC_FASTAPI_URL=
SUPABASE_SERVICE_ROLE_KEY=
ADMIN_API_SECRET=
NEXT_PUBLIC_MAPTILER_KEY=
NEXT_PUBLIC_SENTRY_DSN=
SENTRY_DSN=
SENTRY_ORG=
SENTRY_PROJECT=
```
`NEXT_PUBLIC_FASTAPI_URL` will need to point at whatever your Mac's setup uses (localhost, or let `scripts/dev.mjs` auto-detect your LAN IP like it does on Windows).

## 3. Android — nothing to transfer

- `frontend/android/local.properties` (SDK path) — don't copy this; it's machine-specific and Android Studio regenerates it automatically on first open.
- No release keystore exists yet anywhere (release signing is still a TODO — see the App Links comment in `AndroidManifest.xml`), so there's no keystore file to move.
- `frontend/android/app/src/main/assets/capacitor.config.json`, `capacitor.plugins.json`, `res/xml/config.xml`, `app/src/main/assets/public/` — all auto-generated by `npx cap sync android`, not something to copy.

## 4. iOS — not yet created

`frontend/ios/` doesn't exist yet on any machine (`npx cap add ios` hasn't been run). Nothing to transfer here since there's nothing to transfer from — this gets created fresh when you start iOS setup.

## Quick checklist on the Mac

1. `git clone` (after confirming step above — push first)
2. Recreate `backend/.env` and `frontend/.env.local` from the values above
3. `cd backend && pip install -r requirements.txt` (or your usual venv setup)
4. `cd frontend && npm install`
5. `npx cap sync android` (regenerates the gitignored native config files)
6. Open Android Studio, let it regenerate `local.properties`
